# Jack Burkholder — Database & Data Science Portfolio

A portfolio of projects from my junior-year, NOVA dual-enrollment database and
data science classes (ITE 140 / ITE 256) at Arlington Tech. Covers relational
database design in PostgreSQL, an NLP sentiment-analysis pipeline, and a
written tutorial on Firebase's NoSQL Realtime Database.

**Live site:** https://jackaaburk.github.io/

## Projects

### Celtics25 — Relational Database (PostgreSQL)
Designed a normalized (3NF) relational database in PostgreSQL for the
Boston Celtics' 2024–25 starting five, then wrote a Python/pandas script
that extracts the data into a refreshable Excel PivotTable.
[Read the write-up →](https://jackaaburk.github.io/celtics25.html)

### Polarity Checker — NLP / Sentiment Analysis
An NLP pipeline built with pandas and spaCy that scores sentiment and
subjectivity in open-ended survey responses from Arlington's 2050 community
planning project, then visualizes the results as word clouds and histograms.
[Read the write-up →](https://jackaaburk.github.io/polarity-checker.html)

### Firebase Notes — NoSQL Tutorial
A written tutorial on Firebase's Realtime Database: what a NoSQL, JSON-based
store is, how it compares to PostgreSQL, and how to connect to one from Python.
[Read the tutorial →](https://jackaaburk.github.io/firebase-tutorial.html)

## Tech stack
Python · pandas · spaCy · PostgreSQL · Firebase · HTML/CSS/JS
